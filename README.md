# 시간별 랜덤 클릭 스케줄러 (HourlyClicker)

매 시간, 정해 둔 분(分) 범위 안의 랜덤한 시각에 클릭 매크로를 **한 번** 실행합니다.
마우스는 순간이동하지 않고 사람처럼 곡선을 그리며 움직입니다.

## 파일

| 파일 | 용도 |
|---|---|
| `start_gui.bat` | 설정 창 열기 (편집, 저장, 테스트, 실행) |
| `run_profile1.bat` | 프로필1을 콘솔 창에서 바로 실행 |
| `run_profile2.bat` | 프로필2를 콘솔 창에서 바로 실행 |
| `HourlyClicker.ps1` | 본체 (PowerShell 5.1, Windows 기본 탑재) |
| `profiles\profile1.json`, `profile2.json` | 저장된 설정 (처음 저장할 때 생성) |
| `logs\yyyyMMdd.log` | 실행 기록 |

## 사용법

1. `start_gui.bat` 실행
2. 왼쪽 위에서 **프로필1 / 프로필2** 선택
3. 시간표(00시~23시)에서 시간별로 설정
   - **사용**: 이 시간에 작업할지
   - **시작분 / 끝분**: 이 범위 안에서 랜덤 시각에 실행 (예: 5 ~ 45)
   - **확률미작동 / 확률(%)**: 체크하고 확률을 넣으면, 그 확률에 걸렸을 때 이번 시간은 건너뜀
4. 시간 행을 선택하고 오른쪽 칸에 그 시간의 매크로 입력
   - **F8 키로 좌표 기록**을 켜고 원하는 위치에 마우스를 올린 뒤 F8을 누르면 `CLICK x y` 줄이 추가됨
5. **저장** → **▶ 시작** (또는 창을 닫고 `run_profileN.bat`으로 실행)

## 매크로 명령

```
CLICK x y [r]    좌클릭 (r = 랜덤 오차 반경 px, 기본 3)
RCLICK x y [r]   우클릭
DCLICK x y [r]   더블클릭
MCLICK x y [r]   휠 클릭
MOVE x y [r]     이동만
WAIT a [b]       a~b ms 사이 랜덤 대기
KEY 텍스트       키 입력 (SendKeys 형식: {ENTER}, {TAB}, ^c, %{F4} …)
SCROLL n         휠 n칸 (+위, -아래)
# 주석
```

예시:

```
CLICK 812 455
WAIT 500 1500
CLICK 1030 620 5
KEY {ENTER}
```

## 동작 규칙

- 매 시간 `[시작분 ~ 끝분]` 사이 랜덤한 시각(초 단위까지)에 1회 실행
- **확률 미작동**: 체크된 시간에서 확률에 걸리면 그 시간은 건너뜀.
  한 번 건너뛰었다면 **다음 작업 시간은 확률 판정 없이 반드시 실행**
- **50분 이후 실행**: 어떤 시간에 xx:50 이후에 실행됐다면, **다음 시간은 0~10분 사이**에 실행
  (그 시간이 '사용 안 함'이어도 실행하며, 확률 미작동 판정도 하지 않음.
  그 시간에 매크로가 비어 있으면 직전에 실행한 매크로를 사용)
- 마우스 이동: 3차 베지어 곡선 + 가속/감속 + 미세한 떨림 + 가끔 목표를 살짝 지나쳤다가 되돌아오기,
  클릭 위치 랜덤 오차, 누르는 시간·단계 사이 간격도 랜덤
- 실행 중에는 PC 절전 진입을 막음
- **F12**: 실행 중인 매크로 중단
- 실행 중에 바꾼 설정은 다음 시간부터 반영

## 참고

- 좌표는 실제 화면 픽셀 기준입니다 (DPI 배율 영향 없도록 처리됨). 좌표는 F8 기록 기능으로 잡는 것을 권장합니다.
- 관리자 권한으로 실행된 프로그램 창은 일반 권한 스크립트로 클릭이 안 될 수 있습니다. 이때는 bat 파일을 관리자 권한으로 실행하세요.
- 화면 잠금 상태에서는 클릭이 동작하지 않습니다.
